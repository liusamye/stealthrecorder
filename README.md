# 隐私录音应用 - StealthRecorder

## 项目概述
这是一个为华为鸿蒙4.2设备开发的隐私保护型录音应用，主要特点：
- 录音时最小化状态栏显示
- 界面伪装为普通"语音备忘录"
- 个人使用，不在应用商店发布

## 目标设备
- 华为Mate X2 (TET-AN00)
- 鸿蒙版本：4.2.0

## 功能特性
### 已完成
- [x] 基础录音功能（开始/停止）
- [x] MP4/AAC格式录音
- [x] 44.1kHz采样率，128kbps比特率
- [x] 文件按时间戳命名保存
- [x] 基础权限申请
- [x] 简单状态栏隐藏尝试

### 待实现（优先级排序）
1. [ ] 状态栏隐藏优化
2. [ ] 后台持续录音
3. [ ] 通知栏自定义/隐藏
4. [ ] 界面进一步伪装
5. [ ] 录音文件管理
6. [ ] 设置界面

## 技术实现
- 语言：Java
- 最小SDK：24 (Android 7.0)
- 目标SDK：34 (Android 14)
- 录音API：MediaRecorder
- 存储：应用私有目录

## 隐私考虑
- 仅申请必要权限（录音、存储）
- 录音文件保存在应用私有目录
- 不收集任何用户数据
- 无网络连接功能

## GitHub自动构建

### 方法1：GitHub Actions（推荐）
1. 推送代码到GitHub仓库
2. GitHub Actions会自动构建APK
3. 在Actions页面下载构建好的APK

### 方法2：本地构建
```bash
# 使用Gradle构建
./gradlew assembleDebug

# 输出APK位置
app/build/outputs/apk/debug/app-debug.apk
```

## 安装测试
1. 下载APK到电脑
2. 通过USB连接华为Mate X2
3. 开启USB调试模式
4. 使用ADB安装：`adb install app-debug.apk`
5. 或在手机文件管理器中直接安装
